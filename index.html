实测结论

  • 不加保护时，5.8%（BP）到 6.9%（CSA）的随机配置位翻转会让成像失效或挂死
  • 整体 TMR 效果最好（约 1/15），但 DSP 用量从 173 增至 493
  • 降精度冗余不增加 DSP，最佳方案约 1/4；副本位宽偏离计算值都会变差
  • BP 运行时检查：71 次报警全部自动重跑恢复，无挂死

故障注入模拟的是配置存储器单位翻转，不是辐照试验；结合仿真平台的翻转率，可做设计阶段在轨风险估算。

Algorithms & Primitives · 成像算法与基本算子

CSA 与 BP：两条已上板的成像路径。

两种算法均已在 FPGA 上实现；FFT、CORDIC 等算子可单独授权。

CSA · 调频变标算法

频域相位补偿完成徙动校正与聚焦，围绕 FFT、复乘与外存调度组织规则数据通路。

  1. 方位向 FFT 到距离-多普勒域
  2. Chirp Scaling 相位补偿
  3. 距离向 FFT、压缩与徙动补偿、IFFT
  4. 方位压缩与残余相位补偿，输出复图像

已实现 256²、2048²、4096² 三种规模定点 CSA。

BP · 反投影算法

按轨迹计算每个像素斜距，取样补偿相位，沿合成孔径相干累加。

  1. 距离压缩
  2. 像素与脉冲配对，计算斜距
  3. 插值与相位补偿
  4. 沿孔径相干累加输出

已实现 2048²，提供无保护 / TMR / 运行时检查三种配置。

FFT · 流式变换算子

1024 点、四路、十级并行 SDF FFT，纯 SystemVerilog RTL。

保护变体无保护 / ECC / TMR
时钟约束125 MHz · Vivado 2022.1

CORDIC · 相位到正弦

全展开流水旋转 CORDIC，12 位相位 → 12 位 sin，13 次迭代。

内部 X/Y19 位，不使用 DSP

AXI4-Stream 到 DDR DMA 高速传输引擎 IP

微架构亮点：超轻量资源占用（仅 537 LUT），支持 14 GB/s 饱和突发读写，具备 4KB 边界自动切分。
  • 512 位 AXI4-Full 主机架构，经 Versal NoC 互联至 DDR4，工作频率 300 MHz
  • 独立全双工读写数据通路，读写流水线并发运行互不干扰
  • 硬件实时 4 KB 地址边界自适应切割，符合 AXI 协议规范
  • 每个方向最多 8 个 Burst 在途并发，最大化内存吞吐效率
  • 内建严格参数合规校验与 AXI 总线错误侦测告警逻辑
  • 打包为 Vivado 标准 IP，仅 537 LUT、290 Register

实测验证结果：8 GB DDR4 全空间满负荷灌入并读回，逐拍比对校验；2 轮独立测试各 5 轮全循环全部零错误通过，实测平均读写速率达 14 GB/s。

FAQ · 常见问题

合作前，先把问题问清楚。

评估网表真的免费吗？

是。支持带时间或节点绑定的评估网表，先在你自己的板子上免费实测；达到指标后再谈正式授权，测不通不收费。

IP 可以移植到我们用的平台吗？

100GbE 协议栈基于 Versal Premium 的 MRMAC 硬核开发，支持移植到其他平台；NVMe 支持 Versal / UltraScale+。具体移植范围在签约前书面确认。

网表授权和源码授权怎么选？

快速投产、不改动底层选网表；需要二次开发或承担科研攻关选源码，源码随附 Testbench、验证脚本与参考工程。不确定就先用免费评估网表实测。

辐射仿真能代替束流试验吗？

不能，也不应代替。仿真用于设计阶段评估与加固方案对比，配合 SEM 板级注入可覆盖大部分验证需求；最终鉴定仍建议束流试验。

我们只有算法没有 RTL，能做吗？

可以。提供 MATLAB / Python 模型即可，我们完成定点化、RTL 实现与上板验证，交付与模型逐点比对的结果。

周期和报价怎么定？

梳理需求后书面约定交付物、周期与报价，由技术负责人直接对接，没有中间销售环节。
